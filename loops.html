Mastering Loops in JavaScript

Topic: Loops  |  Language: JavaScript

1. Why Loops?

Loops help you repeat a block of code efficiently without writing it multiple times.

2. Types of Loops in JS

  • for – runs a block for a specific number of times
  • while – runs while a condition is true
  • do...while – runs at least once before checking condition
  • for...of – loops through iterable objects (like arrays)
  • for...in – loops through object properties

3. Examples

// for loop
for (let i = 0; i < 5; i++) {
  console.log("Hello World " + i);
}

// while loop
let i = 0;
while (i < 5) {
  console.log("Number " + i);
  i++;
}

// for...of
const fruits = ["apple", "banana", "cherry"];
for (const fruit of fruits) {
  console.log(fruit);
}

4. Use Cases

  • Displaying list of items
  • Repetitive calculations
  • Traversing arrays or objects

5. Best Practices

  • Avoid infinite loops – always define a stopping condition
  • Use forEach or map for cleaner array iterations when possible

Loops are essential in programming and mastering them helps you write efficient, clean, and reusable code.
